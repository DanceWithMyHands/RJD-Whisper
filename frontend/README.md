# РЖД · Протокол — UI системы документирования совещаний

Интерфейс системы автоматического документирования поручений с совещаний ОАО «РЖД».
Реализован по техническому заданию на стеке **React + TypeScript + Material UI** (Vite).

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173

Сборка production-версии:

```bash
npm run build
npm run preview
```

## Экраны (по ТЗ)

| Экран | Маршрут | Назначение |
|-------|---------|-----------|
| Дашборд | `/` | Сводка по совещаниям и поручениям, метрики исполнения |
| Подключение бота | `/connect` | Подключение бота-участника к конференции (Cisco Jabber / Яндекс Телемост) и сбор согласия на запись у всех участников |
| Запись совещания | `/recording` | Управление аудиопотоком (запись/пауза/стоп), визуализация, этап обработки (S3 → Whisper → идентификация → LLM) |
| Транскрипт | `/transcript` | Транскрипт с идентификацией говорящих, поиск, фильтр по спикеру, подсветка поручений, краткое содержание |
| Поручения | `/assignments` | Список поручений с ответственными и сроками: редактирование, добавление, удаление, массовое подтверждение, рассылка писем, экспорт JSON/PDF |
| Архив | `/archive` | Хранилище прошедших совещаний с поиском и выгрузкой протоколов |

## Особенности

- **Согласие на запись** — запись блокируется, пока все участники не дали согласие (в соответствии с конкурентным преимуществом из ТЗ).
- **Идентификация говорящих** — каждому участнику присвоен цвет, реплики в транскрипте размечены.
- **Поручения** — структурированный список (ответственный + дедлайн + приоритет + статус), выделенный «LLM» из транскрипта.
- **Массовое подтверждение и рассылка** — выбор нескольких поручений, подтверждение и персональные письма каждому ответственному.
- **Экспорт** — JSON (для интеграций) и PDF-протокол (печатная форма ОАО «РЖД»).

## Архитектура кода

```
src/
  components/      переиспользуемые компоненты (Layout, диалоги, чипы)
  pages/           экраны приложения
  store/           MeetingContext — состояние совещания (React Context)
  data/            моковые данные совещания РЖД
  utils/           форматирование, экспорт JSON/PDF
  types.ts         типы предметной области
  theme.ts         тема MUI в фирменных цветах РЖД
```

## Подключение к бэкенду

Данные сейчас моковые (`src/data/mockData.ts`). Для интеграции с FastAPI-бэкендом
запросы можно направлять на `/api/*` — в `vite.config.ts` настроен прокси на `http://localhost:8000`.
Достаточно заменить вызовы в `MeetingContext` на обращения к API.
